Playwright demo framework

Personal project · Public demo targets · No client code
Problem
Client work is confidential, so there was nothing public to show how I structure automation.
Approach
Built a Playwright (JavaScript) framework with the Page Object Model, fixtures for a logged-in state, separated test data, and UI tests on a demo shop plus API tests on a public REST API. Tests run in parallel and keep trace, screenshot and video on failure. A GitHub Actions workflow is included.

18 tests (14 UI, 4 API) pass locally and in GitHub Actions, and stayed stable across repeated local runs. A deliberately broken assertion made a test fail, confirming the checks are real.
